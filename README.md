# English Word Quiz

업로드한 영어 단어/한글 뜻/예문 600개를 이용한 단어 퀴즈 웹사이트입니다.

## 파일
- index.html
- style.css
- script.js
- vocab-data.js

## 실행 방법
1. 네 파일을 같은 폴더에 둡니다.
2. VS Code에서 폴더를 엽니다.
3. index.html을 Live Server로 실행합니다.

## 기능
- 한글 뜻 보고 영어 단어 맞히기
- 예문 빈칸 단어 맞히기
- 빈칸 첫 글자 힌트
- 랜덤/순서 출제
- 문제 수 선택
- 점수 계산
- 오답노트
- 틀린 문제만 다시 풀기


## 수정 사항
- 예문 빈칸 문제는 예문에 실제로 들어간 형태만 정답으로 인정합니다. 예를 들어 `{attempted}`는 `attempted`만 정답이고 `attempt`는 오답입니다.
- 결과 화면에서 틀린 문제만 다시 풀 수 있습니다. 다시 풀다가 또 틀리면 그 문제만 계속 남아서, 맞을 때까지 반복할 수 있습니다.


## 2026-06 업데이트

- 처음 입력한 단어 순서를 기준으로 30개씩 Unit 1~20으로 나누었습니다.
- 설정 화면에서 원하는 Unit을 골라 풀 수 있습니다.
- 정답 확인 후 `Space` 키를 누르면 다음 문제로 넘어갑니다.
- 예문 빈칸 문제는 예문 속 실제 형태만 정답으로 인정합니다.
- 틀린 문제는 결과 화면에서 다시 풀 수 있고, 맞을 때까지 반복할 수 있습니다.
